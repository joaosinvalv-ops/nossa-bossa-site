# Nossa Bossa · site

Site do **Nossa Bossa**, quarteto instrumental do Rio de Janeiro: sax e flauta, piano, baixo e bateria.
Da bossa nova ao jazz, do choro ao pop.

- `index.html` — página única (fotos e fontes embutidas)
- `video/` — vídeos do quarteto (Chega de Saudade, Wave, Ternura)

Pra publicar: arrastar a pasta no Netlify Drop ou ligar este repositório no Netlify / GitHub Pages.
